# Liaison

An agent-native business operating system: your team's mail, tickets, knowledge,
invoicing, shipping and more in one self-hosted workspace, with AI agents that work
alongside you under the same permissions as people.

- **Try it:** [demo.liaison.sh](https://demo.liaison.sh), your own copy of a fictional
  company, agents working out of the box, no model key needed.
- **Self-host it:** [liaison-sh/liaison](https://github.com/liaison-sh/liaison). Clone it,
  open it in Claude Code or Codex and ask "set up Liaison for my company".
- **Read more:** [liaison.sh](https://liaison.sh)
